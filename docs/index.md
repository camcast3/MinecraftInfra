## Can my PC run it?

| Component | Minimum | Recommended |
|-----------|---------|-------------|
| RAM (total system) | 8 GB | 16+ GB |
| RAM allocated to Minecraft | 4 GB | 8 GB |
| CPU | 4 cores | 4+ cores, 3 GHz+ |
| Storage | 10 GB free | 20+ GB on SSD |

The Craft to Exile 2 instance ships **pinned to an 8 GB allocation** with
automatic Java detection, so you don't need to touch Prism's memory settings.
The modpack needs about **8 GB of total system RAM** to run well — on an
8 GB-total PC, lower the allocation to 4 GB in Prism so Windows isn't starved.
